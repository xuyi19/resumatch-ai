## 环境与约定（备忘）

- 后端 conda 环境：`C:\Users\许\.conda\envs\resumatch-ai\python.exe`；测试：`cd backend && python -m pytest tests/`
- 测试直接用开发库 `backend/data/resumatch.db`（conftest 手动 create_all + ensure_schema_columns；ASGITransport 不触发 lifespan）
- 老库升级模式：新增列统一登记在 `app/core/db.py` 的 `_SCHEMA_NEW_COLUMNS`

- 前端路由为 hash 模式（`#/analyze`），自动化导航必须带 `#`
- SQLite 时间戳为 UTC naive；配额/启动补偿的日期比较均按 UTC
