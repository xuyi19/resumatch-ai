# M45 岗位库：自管理岗位 + 多岗位×简历匹配推荐

## Context

用户需求：新增「岗位库」页面（侧栏「简历库」下面），统一管理心仪岗位——优化岗位获取流程，支持**自己添加**（先做）、自动获取（后续），并支持**多个岗位与简历批量匹配推荐**。

现状痛点：岗位数据散落在诊断页岗位面板（AI 生成/示例数据，一次性）与 localStorage 收藏（`resumatch_favorite_jobs`，仅本机浏览器），无统一管理入口，也无法批量与简历比对。

已有可复用基础：
- `_rank_for_resume(resume_text, pool, llm_cfg)`（[jobs.py](e:\code\resumatch-ai\backend\app\api\v1\jobs.py#L58)）：粗筛兜底 + LLM 精排，返回 `[{...job, score, reason}]` + degraded 标志——匹配推荐直接复用
- `JobItem` 数据结构（job_market.py L28）：id/title/company/salary/city/source/jd_text/url
- owner 隔离：`Depends(get_owner_id)`（deps.py）+ `X-Session-Id` 头（测试用）
- 简历库 CRUD/批删模式（resume.py）、页头/列表卡骨架（ResumeListView.vue）

## 实施

### 1. 后端：SavedJob 表（models/entities.py 追加）

```python
class SavedJob(Base):
    __tablename__ = "saved_jobs"
    id / owner_id(String64, index, default="local")
    company(String(60), default="") / title(String(80)) / city(String(20), default="")
    salary(String(40), default="")
    jd_text(Text)                      # JD 全文，核心字段
    source(String(16), default="manual")   # manual 手动 / ai 面板入库
    url(String(300), default="")
    created_at / updated_at(func.now())
```
新表由 `Base.metadata.create_all` 自动建，**无需**登记 `_SCHEMA_NEW_COLUMNS`（那是老表补列用的）。

### 2. 后端：jobs.py 新增端点（router 前缀 /jobs 已有）

- `GET /jobs/library` — 列表（owner 隔离，id 倒序，limit 200）
- `POST /jobs/library` — 添加，body `{items: [{title*, company?, city?, salary?, jd?}], source}`，支持批量；jd 允许空（回退「公司+岗位」占位文本，同 import-match L176 惯例）
- `PUT /jobs/library/{id}` — 编辑（字段可选，None 不更新——Pydantic 可选字段一律 `| None = None` 防显式 null 422）
- `DELETE /jobs/library/{id}` — 单删（owner 校验，404）
- `POST /jobs/library/batch-delete` — `{ids: []}` 幂等返回 deleted 数（参考 resume.py L265 模式）
- `POST /jobs/library-match` — `{resume_id | resume_text 二选一, job_ids?, top_n?, llm_config?}`：resume_id 查 Resume 表（owner 校验 404）→ 库内岗位（或指定 job_ids，owner 校验）构造 JobItem 池 → **复用 `_rank_for_resume`** → `{items, degraded, degraded_reason}`

路由顺序注意：字面路径（/library、/library-match、/library/batch-delete）注册在参数路由 /library/{id} 之前（memory：FastAPI 同前缀路由教训）。

复用 ResumeListView 骨架 + 全站页头规范（渐变标题 + 短横线 + 容器 `max-w-6xl mx-auto px-6 md:px-10 py-8`）：
